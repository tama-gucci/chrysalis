# Engineering privacy
Run the maintained source checker outside the private vault, scanning hidden/ignored/untracked
working files as well as package payloads. Review content for personal tasks, memories, sessions,
device manifests, credentials and user-derived examples; secret-pattern scans alone are insufficient.
Keep recoverable private evidence outside source. Preserve private content before approved source
removal. Default-deny Git/package allowlists are additional guards, never permission to keep private
files in the source folder. Git history is separate and needs explicit remediation if exposed.
