# Read-only diagnostics and reviewed repairs
`doctor` checks registered schemas, local timestamps, pillar tags, WikiLinks, canonical skill
dependencies, and .20–2.00 multiplier bounds. A read-only pass creates no health ledger or fixes.
Missing strict dependencies, invalid records, redirected paths and uncertain observations fail
explicitly. Draft repairs with original revisions: infer missing modality only from evidence,
preserve creation timestamps, convert observed UTC to the date's configured local offset, repair
broken links deliberately and clamp invalid multipliers only after review. Never auto-rewrite on
inspection. A health report may be proposed as System/System-Health.md with actual findings/time.
Schema validation does not establish external integration readiness or physical UI behavior.
