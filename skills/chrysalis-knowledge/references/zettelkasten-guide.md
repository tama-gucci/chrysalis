Create a single-thesis note at Slipbox/YYYYMMDDHHmmss-slug.md with a local timestamp ID, title,
dateCreated, concept/domain tags, provenance source_ref/checksum/URL when observed, and optional
project_ref. Separate Core Thesis, Technical Elaboration, Empirical Application and References.
Conversational ideas may have null provenance; do not invent a source. System ideas use chrysalis
tags and an unintegrated/staged/integrated status rather than pretending implementation happened.
Draft the note and relevant reciprocal links for review. `graph` derives exact existing project
associations and proposes roadmap frontmatter/body links, task linked_zettels and reciprocal Zettel
project_ref changes. Unrelated standalone tasks remain unrelated. Do not fuzzy-match project titles
or count a generic task tag as a meaningful association. Apply through the common receipt boundary.
Ground claims in Sources and link vault-relative originals so knowledge surfaces during task work.
