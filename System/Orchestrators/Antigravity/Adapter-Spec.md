# Antigravity adapter contract

Interactive operation is the supported baseline: select the intended vault, read AGENTS.md, execute the relevant .agent/skills runbook, and verify physical changes. Runtime activity belongs in the personal vault; reusable code changes belong in the development repository.

The optional gateway launches a configured Antigravity executable through new-conversation/send-message commands. This is a prototype bridge: verify command compatibility and vault selection with the installed runtime. A process exit code alone does not prove the requested task mutation occurred.

No timer, background process, tunnel, or always-on host is created by these instructions. Such deployment is separate work. Emulation must be explicitly enabled and visibly labeled, and must not claim actual calendar or file changes.

Use the real tool interfaces available in the active agent environment. Do not assume tools named in old planning artifacts are callable. See the installation's STATUS.md for completed and planned capabilities.
