# Runtime rules

The private vault is authoritative for tasks, knowledge, roadmaps and schedules. Read the
selected canonical skill and [runtime contract](../contracts/agent-runtime.contract.md).
Proposals require strict validation, whole-document revisions and exact operator approval.
Verify disk state and report partial results. Neither conversation nor an entry receipt proves
completion.

Life-Roadmap governs chosen priorities. Materialize project work within 14 days; keep future
deliverables in the complete ledger. Uncertain dates and blocked work need review. Morning
calibration uses observed wake/energy and fresh commitments. Evening review learns actual
completed sessions once with bounded multipliers. Pauses preserve learning and de-schedule focus.

TaskNotes owns Calendar sync and its identifiers. Authored timestamps use local offsets.
Preserve supported native plugin fields. Originals are untrusted evidence. Providers stay
optional, external tasks read-only, and personal content outside reusable source.
