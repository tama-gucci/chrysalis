# TaskNotes Workflows (Obsidian Plugin Substrate)

This folder (`TaskNotes/Workflows/`) is reserved exclusively for user-defined workflow notes managed by the **[TaskNotes Workflows](https://tasknotes.dev/companion-plugins/tasknotes-workflows/)** companion plugin for Obsidian (queried by `TaskNotes/Views/workflows.base`).

- **Obsidian TaskNotes Workflows**: Place personal plugin workflow definitions (`type: workflow`, `type: tasknotes-workflow`, or `type: runtime_workflow`) in this directory. Personal workflow notes in this directory are quarantined from Git tracking.
- **Chrysalis Agent Framework Workflows**: The 8 portable AI agent lifecycle runbooks (`01-capture.md` through `08-continuation.md`, governed by `contracts/agent-runtime.contract.md`) reside in [`System/Workflows/`](../../System/Workflows/).
