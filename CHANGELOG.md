## 2.0.0

Self-contained Pi package with prepared vault onboarding and reusable timezone setup.

- Optional reviewed host add-ons provide bounded Ketch web research during onboarding,
  current-session recall and structured questions. Exact tool origin/definition checks preserve
  native roadmap and per-note approval; that external host-addon policy excludes general executors
  and child agents. Native assistant capabilities have their own isolated policy.

## Assistant integrations

- Native model/capability setup, adaptive teaching and private lesson/diagram work.
- Wrapped memory and fixed specialists with bounded routes, work reservations and role policies.
- Isolated Linux workspace execution and native source/artifact review.
- Optional controlled Chromium research/browser pack; Gemini video acceptance remains deferred.

- Main and child startup refuse required-policy failures before unrestricted tools or model work.

- Operator-reviewed custom chat providers can supply selected memory/specialist models; exact
  source-tree bindings and missing-stream refusal preserve no-fallback behavior.

- Optional private password-export onboarding, encrypted append/update and exact native browser
  login review. Credentials are excluded from ordinary ingestion, source and worker snapshots.
  A future read-only password-manager adapter boundary is documented; sync is not connected.
