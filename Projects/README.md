# Projects

Private project roadmaps live at `Projects/<id>/Roadmap.md`. Use the
[project template](_templates/Project-Template.md) and the knowledge skill. Keep the full
deliverable ledger and evidence links; materialize only reviewed near-term/uncertain work.
Staged exploration is distinct from integration into chosen pillars and active horizons.
Originals share `Attachments/Originals`; source contains only sanitized templates.
